## HenriSpec Discovery

Quando o dev trouxer uma necessidade ainda vaga, uma dor sem solução clara, ou um ticket
escrito com pressa, sugira **uma vez, sem bloquear**: o agente `henrispec-discovery-grill` para
entrevistar a necessidade, ou o `henrispec-discovery-triagem` para um ticket já escrito. Se o
dev quiser seguir direto, siga.

Os agentes `henrispec-discovery-*` só agem quando selecionados. Fora deles, `docs/briefings/` e
`docs/prototipos/` são só consulta.
